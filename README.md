# GM-CNF: Domain-Invariant Semi-Supervised Representation Learning under Continuous Domain Shift

Abstract: Time series analysis in industrial environments faces dual challenges of label scarcity and continuous domain shift. Nonlinear covariate fluctuations (e.g., rotational speed and load) distort data manifolds, causing traditional semi-supervised learning (SSL) models to suffer from negative transfer and confirmation bias. To address this, this paper proposes a Gaussian Mixture Conditional Normalizing Flow (GM-CNF) framework. To tackle manifold distortion, the framework explicitly injects observable covariate priors into an invertible flow network. By actively counteracting nonlinear disturbances, it analytically decouples categorical semantics from environmental interference, extracting domain-invariant representations. Building upon this, the model uses minimal labels to anchor Gaussian centers and leverages unsupervised marginal likelihood maximization for probabilistic soft assignment, guiding unlabeled features toward corresponding class manifolds. Furthermore, exact probability density estimation in normalizing flows naturally enables out-of-distribution (OOD) rejection without architectural modifications. Extensive experiments on five real-world datasets with continuous domain shifts demonstrate that GM-CNF outperforms baselines in closed-set classification accuracy under low label rates, while exhibiting robust open-set detection capabilities, providing a reliable industrial monitoring approach.
